# ☕ CS한잔 (daily-cs-hanjan)

기술스택이 달라도 같이 할 수 있는 CS/AI 기술면접 대비 스터디
완벽한 답보단 **꾸준한 학습과 기록**을 목표로 합니다.

## 진행 방식

1. 매일 `아침 9시`에 자동으로 질문 1개가 [Discussions](../../discussions)에 올라옵니다 (`[CS]` `[AI]` `[네트워크]` `[자료구조]` 등)
2. 답변은 해당 질문의 댓글로 답니다
3. 형식은 완전 자유 — AI로 초안 잡고 다듬기, AI 답변 그대로 쓰기, 순수 자기 생각, 링크만 던지기 전부 가능
4. 마감은 당일 자정(00:00) — 넘기면 그날 문제는 종료. 늦게라도 올리고 싶으면 🐢 이모지 붙여서 편하게 올리기

## 서로 묻고 답하기

- 다른 사람 답변에 궁금한 게 있으면 편하게 대댓글로 질문하기
- 다른 스택 관점에서 나오는 답변 차이도 이해하고 존중하기

## 부담될 땐 스크랩

오늘 답변 못 하거나 부담되면 죄책감 갖지 말고 질문에 🔖 리액션만. 나중에 모아서 다시 봐도 충분!

## 그 외

- 정답 맞추기 대회 아님, 채점 없음
- 참여 강제 없음, 빠지는 날 있어도 괜찮음

## 약속

- 틀린 답도 배움의 과정, 부족한 답변은 없습니다
- 서로 비교하지 않고, 비하하지 않기
