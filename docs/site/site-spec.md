# CS한잔 사이트 기술 명세서

| 항목 | 내용 |
|---|---|
| 문서 상태 | 초안 v1 (요구사항 인터뷰 2회차, AI 제안 3건 확정 반영. 2026-10-15) |


## 1. 배경

GitHub Discussions에 질문과 답변이 누적되면서 과거 답변을 다시 찾기 어렵습니다. 현재는 질문마다 스레드를 열어야 하므로 본인이 과거에 작성한 답변과 다른 참여자의 답변을 한눈에 확인할 수 없습니다.

## 2. 목표 및 비목표

### 2.1 목표

- Discussions의 질문과 답변을 카테고리, 작성자, 검색어 기준으로 탐색하는 읽기 전용 사이트를 구축합니다.
- 새 댓글 등록 후 1분 이내 사이트 반영을 목표로 합니다. 목표값은 실측 후 확정합니다.

### 2.2 비목표

- 사이트 내 댓글 작성 및 수정 기능을 제공하지 않습니다. 댓글 작성은 Discussions에서만 수행합니다.
- 참고 답안 및 핵심 키워드 가이드는 이번 범위에서 제외합니다.
- 신규 참여자의 지난 질문 열람은 우선 지원 대상이 아닙니다.

## 3. 용어

| 용어 | 정의 |
|---|---|
| CS한잔 | 스터디 이름이자 사이트 이름. 사이트를 가리킬 때는 "CS한잔 사이트"로 표기 |
| 아카이브 | 사이트가 보관하는 질문과 답변의 정규화된 사본. 코드 식별자는 `Archive`를 사용 |
| 질문 | GitHub Discussions에 등록된 질문 |
| 답변 | 질문에 등록된 댓글 |
| 마감 댓글 | 토론이 닫힐 때 자동으로 등록되는 댓글 |
| 작성자 | 답변을 등록한 GitHub 계정 |

## 4. 사용 시나리오

| ID | 시나리오 | 사용 페이지 | 동작 |
|---|---|---|---|
| SC-1 | 본인 답변 조회 | 작성자 페이지 | 본인이 작성한 답변을 해당 질문과 함께 조회 |
| SC-2 | 답변 비교 | 질문 상세 페이지 | 동일 질문의 모든 답변을 한 화면에서 조회 |
| SC-3 | 면접 직전 카테고리 복습 | 카테고리 페이지 | 카테고리 내 질문과 답변 확인 |

## 5. 기능 요구사항

| ID | 기능 | 시스템 동작 | 검증 기준 |
|---|---|---|---|
| FR-1 | 카테고리별 열람 | 카테고리별 질문 목록 페이지 제공. 질문 상세 페이지에 답변과 작성자 표시 | 카테고리별 질문 수가 GitHub Discussions 목록과 일치 |
| FR-2 | 작성자별 모아보기 | 작성자 페이지에 해당 작성자의 답변과 해당 질문 표시 | 작성자별 답변 수의 합이 전체 답변 수와 일치 |
| FR-3 | 검색 | 질문 제목과 답변 본문 대상 검색 | 제목 키워드 검색과 본문 키워드 검색 각각에서 해당 항목이 결과에 포함 |
| FR-4 | 새 댓글 반영 | 댓글 생성 시 사이트에 반영. 마감 댓글 제외(C-1) | 댓글 등록 시각부터 화면 반영 시각까지 소요 시간 측정. 목표 1분 이내(실측 후 확정) |

## 6. 제약 사항

| ID | 구분 | 내용 |
|---|---|---|
| C-1 | 마감 댓글 | 토론 종료 시 자동 등록되는 마감 댓글을 반영 대상에서 제외 |
| C-2 | 답변 공개 | 참여 팀원 전원 공개 동의 완료. 저장소 public |
| C-3 | 디자인 | 문서형. 블로그 및 위키와 같이 글 중심의 가독성 높은 레이아웃 |
| C-4 | 서버 | 서버 사용 가능. 기존 운영 중인 EC2 개인 서버 사용 가능 |
| C-5 | 비용 | 추가 비용 없이 운영 |

| 반영 지연 1분 이내 | 확정 |
| 마감 댓글 제외 | 확정 |
| 사이트 이름 `CS한잔` | 확정 |

| 마감 댓글 식별에 숨은 표식과 고정 문구 병행 | 확정(AI 제안 수락). 자동 댓글이 본인 계정으로 등록되어 작성 계정으로 구분 불가 |
| 새 댓글은 해당 질문 부분만 갱신, 거의 즉시 반영 | 확정. 렌더링 방식은 `adr/0001-rendering-strategy.md` |
| 열린 질문 화면은 15초 폴링으로 새 답변 반영 | 확정 |

AI 제안 처리 결과는 수락 3건, 기각 0건입니다.

## 8. 미결정 사항

- 댓글 수정 및 삭제의 반영 여부
- 신규 참여자 합류 시 공개 동의 수집 방식
- 사이트 주소 별도 운영 여부
- 탈퇴 계정(작성자 null) 표시 방식
- 대댓글(답변에 대한 답글) 표시 여부
