# CS한잔 사이트 디자인 명세

| 항목 | 내용 |
|---|---|
| 문서 상태 | 초안 v0 |
| 작성일 | 2026-10-15 |
| 관련 문서 | [site-spec.md](./site-spec.md), [site-structure.md](./site-structure.md) |

## 1. 원칙

- 문서형 레이아웃. 블로그와 위키처럼 글 중심의 가독성을 우선합니다(C-3).
- 장식 요소는 최소화합니다.
- 읽기 전용 사이트이며 입력 UI는 검색에 한정합니다.
- 이 문서의 수치는 초안 기준값이며 구현 후 조정할 수 있습니다.

## 2. 정보 구조

경로는 제안이며 스택 확정 후 고정합니다.

| 페이지 | 경로(안) | 시나리오 | 구성 |
|---|---|---|---|
| 홈 | `/` | 진입 | 카테고리 목록, 최근 질문 |
| 카테고리 | `/category/{slug}` | SC-3 | 질문 목록(최신순), 질문별 답변 수 |
| 질문 상세 | `/q/{number}` | SC-2 | 질문 본문, 답변 목록(작성자, 작성 시각, 본문) |
| 작성자 | `/author/{login}` | SC-1 | 답변 목록(질문 제목과 답변) |
| 검색 | `/search?q=` | FR-3 | 입력창, 결과 목록(질문 제목, 일치 부분 발췌) |

## 3. 공통 레이아웃

| 영역 | 내용 |
|---|---|
| 상단 바 | 사이트명, 카테고리, 검색 |
| 본문 | 단일 컬럼. 최대 폭 720px(초안) |
| 작성자 진입 | 홈과 질문 상세의 작성자명 링크 |
| 하단 | 원본 Discussions 링크, 저장소 링크 |
| 모바일 | 단일 컬럼 유지. 코드블록 내부를 제외한 가로 스크롤 금지 |

## 4. 타이포그래피와 색

| 항목 | 기준값(초안) |
|---|---|
| 본문 글자 크기 | 16~18px |
| 행간 | 1.7 |
| 줄 바꿈 | 한글 단어 단위(`word-break: keep-all`) |
| 글꼴 | 시스템 글꼴 우선. 웹폰트 사용 시 라이선스와 로딩 비용 확인 |
| 색 대비 | 본문 WCAG AA 4.5:1 이상 |
| 다크 모드 | 시스템 설정(`prefers-color-scheme`) 따름 |
| 링크 | 밑줄 유지 |

## 5. 컴포넌트

| 컴포넌트 | 구성 | 사용 페이지 |
|---|---|---|
| 질문 항목 | 제목, 날짜, 카테고리, 답변 수, 마감 여부 | 홈, 카테고리 |
| 답변 블록 | 작성자, 작성 시각, 본문 | 질문 상세, 작성자 |
| 카테고리 표시 | 텍스트 배지 | 질문 항목, 질문 상세 |
| 검색 결과 항목 | 질문 제목, 일치 부분 발췌 | 검색 |
| 코드블록 | 가로 스크롤, 복사 버튼 없음(MVP) | 질문 상세, 작성자 |

## 6. 상태와 예외

| 상태 | 처리 |
|---|---|
| 답변 0건 질문 | "아직 답변이 없습니다" 표시 |
| 작성자 null | 표시명 `탈퇴한 사용자`. AI 제안이며 SPEC 8장 미결정 사항과 연동 |
| 빈 답변 본문 | 작성자와 시각만 표시하고 레이아웃 유지 |
| 긴 코드블록 | 컨테이너 내부 가로 스크롤 |
| 이모지 | 원문 그대로 표시. 글꼴 대체 시 깨짐 없음 |
| 검색 결과 0건 | 안내 문구 표시. 검색어 유지 |
| 없는 경로 | 404 페이지와 홈 링크 |
| 대댓글 | 미결정(`site-structure.md` 14장) |

## 7. 접근성 기준

- 키보드만으로 모든 링크와 검색 사용 가능
- 페이지당 h1 하나, 제목 단계 순서 유지
- 본문 바로가기 링크 제공
- 본문 이미지는 작성자가 제공한 대체 텍스트를 사용하고 없으면 빈 값 처리
- 점검 방식: 자동 점검 도구와 수동 키보드 확인 병행. 자동 점검은 위임 가능

## 8. 검증

| 항목 | 확인 방법 |
|---|---|
| 320px 폭 레이아웃 | 가로 스크롤이 없음(코드블록 제외) |
| 라이트와 다크 대비 | 두 모드 모두 본문 대비 4.5:1 이상 |
| 작성자 null 처리 | 샘플 데이터로 질문 상세와 작성자 페이지 렌더링 |
| 긴 코드블록과 이모지 | 샘플 데이터로 화면 확인 |
| 키보드 탐색 | 마우스 없이 홈에서 질문 상세까지 이동 |
