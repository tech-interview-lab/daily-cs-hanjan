# AI 활용 기록 안내

작업마다 AI에게 맡긴 것과 사람이 확인한 것을 남기는 폴더입니다. PR 본문의 "AI 활용 내역"은 이 기록을 근거로 작성합니다.

## 규칙

| 항목 | 내용 |
|---|---|
| 저장 위치 | `docs/ai/logs/` |
| 파일명 | `YYYY-MM-DD-제목.md` |
| 작성 시점 | 작업 종료 직후. 해당 PR에 포함 |
| 기록 대상 | AI에게 일을 맡긴 모든 작업. 오탈자 수정은 제외 |
| 기재 원칙 | 실제로 한 것만 기재 |
| 수치와 출력 | 명령 출력과 수치는 원문 그대로 붙임 |
| 빈 항목 | 비워 두지 않고 "없음"으로 기재 |
| 금지 | 토큰, 비밀키, 개인정보 |

## 템플릿

```markdown
# YYYY-MM-DD 제목

- 시킨 것:
- AI 결과:
- 내가 고친 것:
- 확인 방법과 결과:
- 틀렸거나 아쉬웠던 점:
```

## 작성 기준

- AI가 틀린 경우 틀린 내용과 발견한 방법을 함께 적습니다.
- AI 결과를 수정 없이 사용한 경우에도 확인 방법을 적습니다.
- AI 제안을 기각한 경우 제안 내용과 기각 사유를 적습니다. PR 본문의 "기각한 AI 제안"에 같은 내용을 옮깁니다.
- 확인하지 못한 항목은 "확인 못함"으로 적습니다.
