- 틀렸거나 아쉬웠던 점:
  - 다크 모드에서 사이드바 현재 항목의 숫자가 대비 4.04로 기준 미달. 디자인 명세의 대비 표에 이 조합(보조 텍스트 / 강조 배경)이 빠져 있었고, 렌더링 측정에서 발견. 배지 텍스트 색으로 바꿔 해결하고 명세 6.2에 추가
  - 없는 카테고리가 404가 아니라 200을 돌려줌. Partial Prefetching이 목록에 없는 경로에 미리 만든 틀을 먼저 보내기 때문. Next.js 문서에서 원인을 확인하고 끔(ADR-0003)
  - 테마 버튼 라벨 조사 오류("시스템로") 수정
  - 처음 계획한 `unstable_cache`가 Next.js 16에서 `"use cache"`로 대체된 것을 패키지 안 문서로 확인하고 변경. `"use cache"`는 클래스 인스턴스를 캡처할 수 없어 캐시 함수 안에서 어댑터를 만들도록 설계
  - `revalidateTag`의 권장값 `"max"`는 무효화 직후 옛 내용을 한 번 더 보여 주므로 S2 웹훅에서는 `{ expire: 0 }`을 써야 함(ADR-0001에 기록)
  - `next/font/local` 대신 Pretendard 동적 서브셋 CSS를 사용(전체 파일 약 2MB를 피하려고). ADR-0003 갱신
  - npm 버그로 lockfile의 플랫폼 패키지가 또 빠짐(세 번째). `npm run check`에 lockfile 검사를 추가해 다시 생기면 바로 실패하게 함
  - 실수로 404 수정 커밋에 실제 대조 테스트가 섞여 들어가 푸시 전에 두 커밋으로 나눔
  - 질문 상세 페이지(S2)가 없어 질문 제목은 원본 Discussion으로 연결. S2에서 사이트 내 상세로 바꿈
